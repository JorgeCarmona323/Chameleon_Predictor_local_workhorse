## Overview

We ran a full CREST/GFN2-xTB+ALPB(water) conformational search on Cyclosporin A (CsA) and validated the resulting ensemble against the experimentally characterized A1 aqueous conformer (Limbach et al., JACS 2022; Bhatt et al., JACS 2022). The goal was to confirm that the pipeline captures the correct aqueous fold before extending it to a library of cyclic peptides.

## A1 Fingerprint — Reference

The A1 conformer is the dominant aqueous form of CsA. Four structural criteria define it (Limbach et al., JACS 2022, SI Table S11):

| Criterion | Description | NMR evidence |
|---|---|---|
| 1 | **Cis amide at MeVal11-MeBmt1** (ω ≈ 0°) | Hα-Hα ROE cross-peak |
| 2 | **Abu2 NH intramolecularly H-bonded** to MeLeu10 C=O | Temperature slope −2.6 ppb/K |
| 3 | **Ala7 NH intramolecularly H-bonded** to Val5 C=O | Temperature slope −2.07 ppb/K |
| 4 | **Val5 NH solvent-exposed** (not H-bonded) | Temperature slope −7.33 ppb/K |

| Criterion | Result | Pass? |
|---|---|---|
| Cis amide at MeVal11-MeBmt1 | 0.0% of ensemble | ❌ |
| Abu2 NH H-bonded | 69.9% Boltzmann weight | ✅ |
| Ala7 NH H-bonded | 49.6% Boltzmann weight | ✅ |
| Val5 NH solvent-exposed | 78.8% Boltzmann weight | ✅ |
| Full A1 match | 0.0% | ❌ |

**3 of 4 criteria pass. The cis-amide geometry is completely absent from the ensemble.**

All 23 conformers are fully trans (all ω > 150°). No cis amide bond was found in any conformer at any Boltzmann weight.

---

## Root Cause: The Cis-Trans Barrier Problem

CREST's iMTD-GC metadynamics cannot cross cis-trans amide barriers (~15–20 kcal/mol). The input structure (generated by ETKDGv3/RDKit) defaults to all-trans, and the entire conformational search remains trapped in the trans basin. The A1 conformer, which requires a cis amide at MeVal11-MeBmt1, is never sampled regardless of how long the run is.

This is not a failure of the force field or the ALPB solvation model — the H-bond network (criteria 2–4) is correctly reproduced. The problem is purely a sampling limitation.

This is consistent with Witek et al. (J. Chem. Inf. Model. 2016), who showed that single-start MD cannot cross cis-trans barriers even at 400K over 100 ns.

---

## Open Question: Are the Descriptors Still Useful?

Despite missing the cis geometry, 3 of 4 A1 criteria pass. The backbone H-bond network is substantially correct in the dominant conformers. This raises an important question:

**If the H-bond and solvent-exposure features are captured even without the correct cis geometry, do the 3D descriptors derived from this ensemble retain predictive power for permeability?**

This is worth testing empirically: compute the full descriptor set (PSA_exposed, nHBD, Rg, ΔG) from the all-trans ensemble and compare against known permeabilities. If the model still discriminates permeable from impermeable compounds, the cis geometry may matter more for mechanistic interpretation than for ML prediction. If it fails on boundary cases (CycH-type false positives), that would confirm the cis-amide features are load-bearing.

## New Direction: Multi-Start Cis/Trans Enumeration (v3.3)

To fix the sampling gap, `crest_v3.3.py` implements a multi-start approach:

1. **Enumerate** all N-Me amide bond cis/trans combinations (2^k states, k = number of N-Me bonds; capped at 16 starts)
2. **Drive** each combination to the target geometry using xTB constrained optimization (dihedral constraints via `$constrain` blocks)
3. **Run parallel CREST** from each surviving start (ThreadPoolExecutor, 4 threads/start minimum)
4. **Pool** all rotamer files → cregen → final Boltzmann-weighted ensemble

For CsA (7 N-Me amide bonds): up to 16 starts covering all major cis/trans isomers, including the MeVal11-MeBmt1 cis state required for the A1 conformer.

**Expected outcome:** The cis-containing ensemble will include A1-like conformers and allow computation of ΔG(A−C) — the key bias index for the permeability ML model.

## GPU Pipeline Consideration (MACE-OFF)

As a parallel track, we benchmarked MACE-OFF23(M) as a GPU-accelerated replacement for CREST/xTB. Single-point energies on the 23 CsA water conformers gave:

| Metric | Value |
|---|---|
| Pearson r (relative energies, MACE vs xTB) | +0.217 |
| C1 rank shift | +21 (xTB rank 1 → MACE rank 23) |
| Verdict | Failed benchmark gate (threshold r > 0.85) |

**Cause:** MACE-OFF is gas-phase; xTB includes ALPB(water) solvation. The A conformer (C1) is specifically stabilized by water — without solvation, MACE ranks it last. An explicit TIP3P + MACE simulation (feasibility test currently running on RTX 4090) will determine whether the full solvated pipeline is viable at library scale.
