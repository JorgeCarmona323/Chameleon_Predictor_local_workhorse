## The pipeline these notebooks cover

```
SMILES ──▶ 1. GENERATE ──▶ 2. SCORE ENERGIES ──▶ 3. DESCRIBE ──▶ 4. PLOT
           CREST/GFN2-xTB   xtb single-points     Boltzmann-wtd    figures
           per solvent      (CPCM-X / ALPB)       3D descriptors
                            → ΔG_transfer
```

Note stage 2 has **no notebook** — the energy/ΔG_transfer step postdates this set. It runs via
`scripts/free_energy_calculator.py` (see root README).

## Current ensemble layout (what stage 1 actually writes)

```
results/conformers/<compound>/
  water/    ensemble.xyz   ensemble.sdf   metadata.json
  chcl3/    ensemble.xyz   ensemble.sdf   metadata.json
  hexane/   ensemble.xyz   ensemble.sdf   metadata.json
```

- `ensemble.xyz` — multi-frame; **per-conformer CREST/GFN2 energy is the first float on each comment line**
- `ensemble.sdf` — same conformers, for RDKit
- `metadata.json` — smiles, name, charge, solvent, label, n_conformers

The legacy `ensemble.json` (with `conformers[].totalenergy` / `.boltzmannweight`) is **no longer
produced**. `scripts/ensemble_descriptors.py` reads both layouts, so it works on old and new data.

## Energies and weights — a note on the geometry-first framing

An earlier version of this README said energies and Boltzmann weights were kept only as
*metadata/QC*, with the analysis summarizing the geometric **distribution** (medians/IQRs) over an
RMSD-deduplicated set. That framing is still valid for distribution figures, but the pipeline now
also supports proper **energy weighting**:

`scripts/free_energy_calculator.py` computes solvated single-point populations (CPCM-X/ALPB), and
`ensemble_descriptors.py --energies-csv <that CSV>` weights descriptors by them rather than by raw
GFN2 energies. Use whichever the question calls for — distributions for "what shapes exist",
Boltzmann means for "what does the ensemble actually look like at 298 K".

## Note on the 3D-PSA definition

The 3D-PSA of record follows the **Ono 2019 / Begnini 2021** convention: SASA over N/O + polar
hydrogens, with the Ertl sulfur rule (reduced sulfur contributes 0). Any `psa` field inside a legacy
`ensemble.json` uses an older definition and is **not** used downstream.
